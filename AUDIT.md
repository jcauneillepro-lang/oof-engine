- **Working Session** (`working_session`) — Workshop pre-read. Shape: Context · Prompts · Options · Decisions captured.

- **First 90 Days** (`first_90_days`) — New-hire playbook. Shape: Context · 30 · 60 · 90 · Stakeholders · Derailers.
- **Search Brief** (`search_brief`) — Executive search role brief. Shape: Role · Market map · Profile · Pipeline · Calibration.
- **Field Pulse** (`field_pulse`) — Quarterly field / commercial pulse. Shape: KPI row · Movements · Pulse signals · Recommendations.

## Known gaps · what's still missing

Things to consider for future versions:

- **Few-shot canonical briefs in prompt.** The 4 finished example briefs (Exec/ELT/Annual/SWP) are not included in the system prompt. Adding them as anchors would dramatically improve fidelity to house style, at the cost of ~30K tokens.
- **PPTX export uses screenshot path.** Currently produces non-editable slides. v2 roadmap: structured JSON from Claude → native python-pptx with editable text frames.
- **No template-skeleton picker yet.** Users can pick archetype + cover + divider style but not 'start from this specific brief'. A skeleton picker (NACO Pulse / CDIO ELT / Teaming Roadmap) would lock structural fidelity for repeat workflows.
- **Live preview is iframe-based.** Works fine but limits engine→preview interactivity. A dedicated preview pane with edit-in-place would let the user tweak generated briefs.
- **No user accounts / brief history.** Generations don't persist. Adding a simple per-session history would let the team revisit recent work.
- **Mobile UI not optimised.** Currently desktop-first.
